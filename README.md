# 🤖 Multiple AI Chatbot Projects (RAG-based Context Aware Assistants)

This repository contains **multiple AI Chatbot projects** built using **LLaMA 3 LLM**, **LangChain framework**, and **Python**, focusing on **Retrieval-Augmented Generation (RAG)** to create **context-aware AI assistants**.

These chatbots are designed to retrieve relevant information from custom knowledge sources and generate accurate, grounded responses instead of hallucinated answers.

---

## 🚀 Key Features

- 🔍 **Retrieval-Augmented Generation (RAG)**
- 🧠 **Context-aware AI responses**
- 🦙 **LLaMA 3 as the core Large Language Model**
- 🔗 **LangChain for chaining, prompting & retrieval**
- 📄 Supports multiple data sources (PDFs, text files, web content)
- 🧩 Modular and scalable chatbot architecture
- 💬 Conversational memory support
- 🛠️ Easy to extend for Agentic AI workflows

---

## 🏗️ Tech Stack

| Component | Technology |
|---------|------------|
| Programming Language | Python |
| LLM | LLaMA 3 |
| Framework | LangChain |
| Vector Store | FAISS / Chroma (configurable) |
| Embeddings | HuggingFace / OpenAI-compatible |
| UI (optional) | Streamlit |
| Architecture | RAG (Retriever + Generator) |
